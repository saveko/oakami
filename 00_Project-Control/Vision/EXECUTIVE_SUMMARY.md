## Project Overview

**Oakami OS Version 1** is a focused, single-product release delivering:

### Core Product
**Review Collection + AI Review Reply System**

The application automatically collects reviews from multiple online platforms (Google, Facebook, TripAdvisor, etc.), classifies them using AI, generates professional replies, routes them through manager approval, and sends them back to the source platforms. Daily reports and notifications keep the team informed.

### Scope (LOCKED)
- Review collection from 5+ sources
- AI-powered sentiment & tone classification
- Automatic professional reply generation
- Manager approval workflow
- Multi-location support
- Daily automated reports
- Notification system

**NO additional features, modules, or products in V1.**
